## Critical Issues Found

### 🔴 Issue #1: Duplicate Column in bank_notifications
**Problem:** Database has both `rejectedAt` and `rejected_at` columns  
**Root Cause:** Column was renamed from camelCase to snake_case but old column wasn't dropped  
**Impact:** Schema validation fails  
**Solution:** Migration 14→15 to recreate table without duplicate
